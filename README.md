# AARAM Foods — Factory ERP v4.0

Live app: https://aaramdeva.github.io/aaram-production-erp

## About
FMCG Manufacturing ERP for AARAM Foods, Bhuvanagiri, Cuddalore.

## Features
- Formula Builder (dynamic ingredients)
- Batch Production Entry
- Stock Ledger (auto deduction)
- Production Analytics
- Operator Worksheet (printable)
- Product Costing
- Firebase Realtime Sync
- Works offline
- Installable on phone and laptop
